Principal Component Analysis

Student Data Project | B.Tech Mathematics | B5

Welcome to PCA Student Analytics

This project demonstrates how Principal Component Analysis reduces student marks across five subjects into fewer dimensions.

Dataset: 30 students and 5 subjects

Mathematical Model

Centered data: Xc = X − μ

Covariance: C = XcᵀXc / (n − 1)

Eigenvalue equation: Cv = λv

Projection: Z = XcW

PCA selects the eigenvectors corresponding to the largest eigenvalues to represent the data in fewer dimensions.
